# Delivery Intelligence AI 🚀

### Assistente de IA generativa para triagem de ocorrências em operações de delivery

## 1. Sobre o projeto

O Delivery Intelligence AI é um projeto experimental que explora o uso de Inteligência Artificial Generativa para identificar, classificar e organizar ocorrências relacionadas a pedidos de delivery.

A proposta é transformar relatos de clientes em informações estruturadas, facilitando a análise e o encaminhamento de problemas.

## 2. Problema identificado

Operações de delivery recebem diferentes tipos de ocorrências, como atrasos, pedidos incompletos, itens incorretos e problemas na entrega.

A análise desorganizada desses relatos pode dificultar a identificação do problema e a definição do próximo passo.

## 3. Solução proposta

Um assistente de IA que:

- Classifica o tipo de ocorrência.
- Resume o relato do cliente.
- Identifica informações que estão faltando.
- Sugere encaminhamentos.
- Classifica a prioridade.
- Recomenda análise humana quando necessário.

## 4. Testes realizados

### Teste 01 — Pedido incompleto

**Entrada:** Cliente relata que recebeu o pedido com dois itens faltando.

**Resultado:** A IA identificou a ocorrência como pedido incompleto, apontou informações faltantes e recomendou consultar os detalhes do pedido antes de orientar uma solução.

### Teste 02 — Atraso na entrega

**Entrada:** Cliente relata que a entrega está muito atrasada e demonstra irritação.

**Resultado:** A IA classificou a ocorrência como atraso na entrega, identificou informações necessárias para investigação e recomendou consultar o status atualizado do pedido.

## 5. Princípios de funcionamento

- Não inventar informações.
- Não prometer reembolsos ou compensações sem autorização.
- Evitar solicitações desnecessárias de dados pessoais.
- Diferenciar fatos de suposições.
- Encaminhar situações delicadas para análise humana.

## 6. Próximas melhorias

- Criar critérios objetivos para classificação de prioridade.
- Ampliar a quantidade de cenários de teste.
- Construir uma base de conhecimento simulada.
- Explorar automação e integração com ferramentas de IA.
- Avaliar a consistência das respostas.

## 7. Tecnologias e abordagem

- ChatGPT / IA generativa.
- Engenharia de prompts.
- GitHub para documentação e versionamento do projeto.

**Status:** Protótipo experimental em fase inicial. Os testes apresentados foram realizados com situações fictícias no ChatGPT. Ainda não existe integração com sistemas reais de delivery.
